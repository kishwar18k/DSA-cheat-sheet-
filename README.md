Main:
*Algorithm: step by step procedure to solve a given problem 
*Asymptotic Notation: A mathematical framework to compare one algorithm to another
*It's majorly of 3 types: 
BIG O: WORST CASE or upper bound
BIG THETA: AVG CASE OR Exact time
BIG OMEGA: Best Case or Lower bound
*Time complexity: It is the rate of time increase as the input size increases.
*Space complexity: The memory space taken by the algorithm to run.
input space: space taken to run the problem 
axillary space: space taken to store the problem
